# Кондуит

Внутренняя версия кондуита математического кружка 11 класса, 2026/27.
Учёт плюсов на занятиях: кондуит по сериям, общий рейтинг и пересчёт рейтинга
по любому подмножеству серий и тем.

Сервера и базы данных нет. GitHub Pages раздаёт репозиторий как есть, страница
читает файлы из `data/` и считает всё в браузере читателя. Читать может кто
угодно по ссылке, писать — только владелец репозитория.

## Счёт

Вес задачи = **max(n − число решивших, 1)**, где n по умолчанию равно числу
учеников в списке. Задачу, которую сдали трое из двадцати, она оценит в 17;
задачу, которую сдали все, — в 1: решена же.

n задаётся во вкладке «Очки» редактора и лежит в `data/config.json`
(`scoring.n`). Пока оно не задано (`0`), n равно числу учеников и меняется
вместе со списком — это удобно, пока группа собирается. Как только состав
устоялся, задай n явно: иначе новый ученик переоценит все прошлые задачи задним
числом.

У задачи бывает **своя цена** — тогда формула к ней не применяется. Формула
знает одно: сколько человек сдали. А задача бывает дорога и не поэтому. Своя
цена ставится у каждой задачи отдельно, и её всегда можно вернуть к формуле.
Ноль руками поставить можно: это не то же самое, что «нет своей цены».

У гроборешения бывает **надбавка** — сколько добавить за конкретное «кто взял
этот гроб». Она прибавляется к цене гроба и достаётся только тому, кому
поставлена.

В рейтинге сначала очки, при равенстве — по алфавиту; одинаковых мест не
бывает. В кондуите ученики стоят по алфавиту: там ищут человека, а не место.

## Что где лежит

```
index.html          сайт: рейтинг, кондуит по сериям, гробарий, зачёт, карточка
edit.html           редактор: ввод с телефона
assets/             стили и скрипты
data/
  config.json       название, n в формуле, репозиторий, подпись
  students.json     ученики
  types.json        темы: разделы и подразделы
  graves.json       гробарий: задачи вне серий и кто их взял
  series/NN.json    одна серия
  series/manifest.json  список файлов серий
  zachet.json       список файлов зачёта
  zachet/*.pdf      сами файлы
tools/build.py      версия статики (после правки стилей и скриптов)
```

Формат серии:

```json
{
  "n": 7,
  "series": 5,
  "date": "2026-09-15",
  "problems": [
    { "id": "0", "type": "algebra", "sub": "inequalities", "exercise": true },
    { "id": "2а", "type": "comb", "sub": "graphs", "exercise": false, "weight": 12 }
  ],
  "solved": { "ivanov-artem": ["2а"] }
}
```

`series` — номер серии, он и виден на сайте. `n` — служебный слот: он же имя
файла и ключ внутри редактора; менять его нельзя, иначе перенумерованная серия
потеряет свой файл. `weight` есть только у задач со своей ценой.

Упражнение узнаётся по номеру: числовая часть равна нулю (`0`, `0а`) — значит
упражнение. Поле `exercise` лишь повторяет это в файле.

Задача, чей подраздел удалили из тем, остаётся **без темы**: в рейтинг она не
идёт, пока ей не выберут тему заново, но в кондуите видна — с серой полоской.
Вкладка «Сохранение» показывает такие задачи списком.

## Редактор

`edit.html` открывается в браузере телефона. Один раз нужно вставить
fine-grained токен GitHub с доступом только к этому репозиторию и правом
**Contents: Read and write** — вкладка «Сохранение». Токен лежит в localStorage
телефона и уходит только на `api.github.com`; если телефон потерялся, токен
отзывается в настройках GitHub.

Правки живут в памяти страницы и уезжают **только по кнопке «Сохранить»** во
вкладке «Сохранение»: она одна отправляет всё накопленное — учеников, темы,
серии, гробарий, зачёт, настройки. Уход со страницы теряет несохранённое, ничего
не переспрашивая; переключение между вкладками и сериями — нет. Рядом кнопка
отката. Между сохранениями две минуты перерыва.

- **Серии** — лента по номерам. «+ серия» заводит новую сразу в ленте, в
  репозиторий она уедет по кнопке сохранения. Первое «+ задача» даёт упражнение
  (номер 0), дальше номера идут подряд. «+ пункт» превращает задачу `5` в `5а` и
  добавляет `5б`; пунктов не больше шести. Касание клетки ставит и снимает плюс.
- **Гробы** — задачи вне серий, копятся весь год. Отдельно ведётся список
  гроборешений: кто, какой гроб, какая надбавка.
- **Зачёт** — pdf, которые надо раздать. Файл выбирается с телефона, до 8 МБ, и
  уезжает той же кнопкой сохранения.
- **Темы** — разделы и подразделы. Удаление раздела освобождает его цвет;
  последний раздел удалить нельзя.
- **Ученики** — список группы. Плюсы удалённого остаются в файлах серий:
  считаться перестают, но вернутся, если завести человека снова с тем же именем.
- Удаление где угодно спрашивает дважды: крестик раздваивается на «удалить» и
  «передумал».

## Чтобы редактором нельзя было испортить сайт

- Список серий не считается по памяти страницы: при каждом сохранении он берётся
  из самой папки `data/series`, плюс записанное сейчас, минус удалённое. Любое
  расхождение уходит при ближайшем сохранении само. Пустой список не пишется.
- Файл, о котором редактор не знает, не переписывается: это всегда чужие данные.
- Непрочитанное не правится: если список серий, гробарий или зачёт не
  загрузились, вкладка показывает сообщение, а не пустой список.
- Настройки пишутся по одному полю — тому, которое правили.
- Сайт переживает порчу данных: пропавший файл серии пропускается, пропавший
  список серий — тоже; страница откроется без серий, но откроется.

## Как обновляется сайт

Любая правка в ветке `main` выкладывается GitHub Pages сама, обычно меньше чем
за минуту. Отдельной кнопки «опубликовать» нет.

После правки стилей или скриптов нужно проставить версию — иначе браузер
телефона неделю показывает старый кэш:

```
python tools/build.py
```

Перед первым сохранением из редактора впиши в `data/config.json` имя своего
репозитория (`repo.name`) и свой id в `admin`, если хочешь значок у имени.
